🔒 Arquitectura y privacidad

Local-first y minimización de datos

La mayor parte del procesamiento técnico se realiza directamente en el navegador o en el propio dispositivo mediante recolectores locales. Cuando una herramienta necesita información externa, se limita a los datos necesarios para ejecutar esa función.

  • Sin cuenta obligatoria en las suites principales.
  • Persistencia local mediante tecnologías como IndexedDB.
  • Exportación, importación o borrado cuando el módulo lo permite.
  • Resultados reutilizables dentro de Mi Tecnología y Mi Laptop.
  • Recolectores locales de solo lectura para Windows y macOS cuando la auditoría necesita evidencia del sistema operativo.
  • Los estados desconocidos permanecen desconocidos: ausencia de evidencia no equivale a “sin riesgo”.

🆕 Mejoras recientes

Auditoría Express ahora es multiplataforma

El mismo flujo de Auditoría Express admite Windows y macOS, comparte evidencia con Mi Laptop y conduce a verificaciones manuales cuando el sistema operativo no puede confirmar un estado.

⚡ Windows + macOS

Auditoría Express

Mantiene una sola herramienta pública y dos recolectores locales de solo lectura. Windows conserva PowerShell y macOS utiliza utilidades nativas del sistema.

  • CPU o Apple Silicon, RAM y versión del sistema.
  • Batería, ciclos y condición cuando están disponibles.
  • SSD físico, APFS, S.M.A.R.T. y desgaste NVMe compatible.
  • FileVault, SIP, MDM local, ADE (antes DEP) y Activation Lock cuando existe evidencia concluyente.

🍎 Evidencia macOS

SSD físico y estados conservadores

En Mac, el diagnóstico intenta resolver APFS → Physical Store → disco físico para evitar presentar “Container” como modelo del almacenamiento.

  • “Desgaste NVMe” se separa del espacio ocupado.
  • Activation Lock desconocido no significa desactivado.
  • MDM local no detectado no certifica ausencia de asignación externa.
  • Los datos ausentes no se convierten en cero, falso o “seguro”.

🔐 Evidencia cruzada

Bloqueos y Gestión Anterior

La herramienta distingue Windows y macOS y puede reconocer evidencia previa de Auditoría Express sin marcar automáticamente como completadas las verificaciones humanas.

  • Windows: BIOS/UEFI, TPM, Secure Boot, Entra, dominio y Autopilot.
  • macOS: Activation Lock, Gestión de Dispositivos, MDM, ADE y Remote Management.
  • Una observación manual crítica posterior prevalece sobre una señal automática favorable.

🔐 Seguridad

Auditoría de equipos propios o autorizados

Estas herramientas tienen fines de diagnóstico, educación, análisis preventivo, privacidad, mantenimiento, evaluación de compras y resiliencia digital. Los módulos relacionados con Activation Lock, FRP, MDM, ADE, Remote Management u otros controles detectan e interpretan señales de vinculación; no están diseñados para evadir controles de acceso. Una ausencia de señal local no se presenta como certificación absoluta de propiedad o de ausencia de gestión.
